# Atividades do reforço em programação
Este repositório servirá para a distribuição dos exercícios do reforço. Tanto os sdocumentos PDF como as resoluções.

## Organização do repositório

Este repositório será dividido em pastas contendo listas e atividades.

### As pastas serão distribuidas em: Listas e trabalhos.

Dentro da pasta das pastas também terá a resolução do exercício (feita por mim, se o seu código for diferente, compare as saídas, não o código!)

No possível darei dicas para uma resolução facilitada, mas se possível não use-as!
